# React + TypeScript + Ant Design 小项目

一个基于 **React + TypeScript + Ant Design** 的后台示例项目，包含登录页、菜单布局切换（顶部/左侧）和昼夜主题切换。

## 功能

- 登录页（用户名 + 密码表单）
- 登录后进入后台主界面
- 菜单位置可切换：
  - 左侧导航
  - 顶部导航
- 主题模式可切换：
  - 白天模式
  - 黑夜模式

## 本地运行

```bash
npm install
npm run dev
```

默认启动后访问终端输出中的本地地址（通常是 `http://localhost:5173`）。

## 构建

```bash
npm run build
```
